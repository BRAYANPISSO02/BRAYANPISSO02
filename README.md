### Selected Work

* **Automated Vector Generation (Deep Learning)** — Built a computer vision pipeline in PyTorch using the Segment Anything Model (SAM) and image-to-image translation on Amazon SageMaker to convert photographs into laser-ready SVG vectors, reducing manual design time by ~2 hours per image.
* **Long-Range Telemetry Pilot (PCI Research Group)** — Engineered a data acquisition system for 8 electric energy meters at UNAL (La Nubia Campus) using Modbus RTU/TCP and DLMS/COSEM over Wi-Fi HaLow multi-hop mesh networks, integrated with ThingsBoard.
* **Hardware & PCB Design** — Schematic capture, 2D/3D PCB layout in KiCad, board prototyping, and mechanical enclosure design for CNC and laser fabrication.
